## 全部知识

### cold / 冷藏箱作业 / reader / target

冷藏箱放置阴凉处。
箱温高于8度暂停装箱，恢复合规后再开工。

### gloves / 手套标准 / reader / target

采摘手套须为白色。破损立即更换，雨天禁止使用棉手套。

### bins / 周转筐消毒 / reader / target

周转筐每日收工后以清水冲洗，污筐不得装果。

### scale / 天平检查 / reader / target

天平开工前归零，偏差超过2克停用。校验只能由值班员签字。

### gate / 夜间入园 / reader / target

夜间访客须由保安陪同，员工凭胸卡进入，无需陪同。

### power / 停电处置 / reader / target

停电后关闭输送带，复电先试空载三分钟再上果。

### labels / 标签颜色 / reader / target

出口果箱使用蓝色标签，内销使用黄色标签，不得互换。

### samples / 留样时长 / reader / target

每批留样保存两天。温度异常批次保留四天，疑似污染批次不得放行。

### rain / 雨后复工 / reader / target

雨后地面无积水方可复工。雷电预警未解除时仍须停工。

### load / 装车签收 / reader / target

装车前点清箱数，双方签署交接单。缺少司机签字不得出车。

### fallen / 跌落处置 / reader / target

落地果只送堆肥区，不得混入商品箱。疑似受污染果须隔离。

### spill / 溢液处置 / reader / target

清洁液泄漏先围挡，再通知值班员，未经确认不得恢复通行。

### battery / 电池存放 / reader / target

备用电池放干燥柜，鼓包电池送回收点，不得充电。

### access / 门禁故障 / reader / target

门禁故障由保安人工核验胸卡，访客仍须陪同。不得分享胸卡。

### dispatch / 出车复核 / reader / target

交接单由仓管存档。
司机签字后还须由门岗确认封条完好。

### restart / 异常复工 / reader / target

温控异常复工须由值班员确认。食品污染疑点必须由质检员解除。

### foreign-gloves / 手套标准 / other / other

采摘手套须为白色。破损立即更换，雨天禁止使用棉手套。

### sibling-gloves / 手套标准 / reader / sibling

私域试验区采摘手套为黑色，只适用于本区。
